# Asset provenance

All project-specific visual geometry, colors, text, names, layouts, the shield
icon and synthesized sound cues were authored for this project. No downloaded
game art, commercial character, copied map, dialogue or franchise asset is used.

World geometry is built by `Geometry`, `WorldProp`, `ActorVisual`, `Terrain` and
`Road`. Audio is generated by `combat_audio.gd`. UI uses Godot's bundled fallback
font. Godot is distributed separately under its own license; see
https://godotengine.org/license/ and the engine's About/License panel when making
a distributable build.

No project-wide open-source license has been chosen on the user's behalf.
